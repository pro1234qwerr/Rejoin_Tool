# Roblox Rejoiner

Herramienta para monitorear y relanzar automáticamente Roblox en instancias de MuMu Player.

## Características

- Detección automática de puertos ADB de instancias de MuMu Player
- Monitoreo en tiempo real del estado de Roblox
- Relanzamiento automático de Roblox con un ID de juego específico
- Interfaz gráfica intuitiva
- Sistema de autenticación por claves
- Actualizaciones automáticas
- Protección contra análisis y manipulación

## Uso

1. Ejecuta la aplicación
2. Ingresa tu clave de licencia (si es necesario)
3. Ingresa el ID del juego de Roblox al que quieres hacer rejoin
4. Configura el intervalo de verificación
5. Haz clic en "Iniciar monitoreo"

La herramienta detectará automáticamente las instancias de MuMu Player y monitoreará Roblox en cada una de ellas.
